# Make: הרשימה המאוחדת

Sep 29, 2026

**מה נכנס:** 50 המובילים של הסבב השני, 50 המובילים של הסבב השלישי, וארבעת הרעיונות שלך (שלחת ארבעה). סך הכול 104.

1. **קיבוץ:** רעיונות עם אותו קלט ואותה צורה אוחדו לפריט אחד עם כמה סגנונות. העמודה "מקור" מראה מה נכנס לכל פריט (R2-n ו-R3-n הם המספר בסבב השני ובסבב השלישי).
2. **מחיקה:** נמחק כל מה שכבר קיים באתר, או שמוצר קרוב מאוד אליו קיים (5 פריטים).
3. **צבע:** נפסל כל מה שדורש הדפסה צבעונית (1).
4. נשארו **72 פריטים**, והם קיבלו ציון מחדש.
